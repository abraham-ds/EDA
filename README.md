# EDA
This repo contains EDA projects to showcase the power of Python and different statistical and data processing libraries available.

**Exploratory Data Analysis (EDA)** is a critical step in data science that involves analyzing and summarizing datasets to uncover patterns, relationships, and anomalies.

---
## Table of content

In this repository you will find the following projects:

1. **Healthcare Analytics:** Hospital Readmissions Analysis
2. **Employee Attrition:** Discovery if there is any significant variables that indeed affect employee attrition. rank the variables from most important to the least.
